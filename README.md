# てがきカレンダー サポート

写真と手書き数字を組み合わせて、飾って楽しめるカレンダーを作るiPadアプリです。

- [使い方とよくある質問](support.md)
- [プライバシーポリシー](privacy.md)
- [不具合・ご要望のお問い合わせ](https://github.com/yzma0106-afk/tegakical-support/issues/new/choose)

お問い合わせに、お子さまの本名・生年月日・顔写真や、個人情報が含まれる作品ファイルを添付しないでください。
GitHubのIssueは公開されます。画面画像を添付する場合は、個人情報を隠してください。

このリポジトリはサポート資料専用です。アプリのソースコードや利用者の作品データは公開しません。
